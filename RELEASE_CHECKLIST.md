# Release Checklist

- [ ] Verify every medicine, brand, strength, composition and registration number against current DRAP data.
- [ ] Pharmacist/clinical review completed.
- [ ] Replace placeholder developer contact information in privacy policy.
- [ ] Host privacy policy on a public HTTPS URL.
- [ ] Create/verify Google Play Console developer account and package name.
- [ ] Configure final signing/Play App Signing.
- [ ] Build and test a release Android App Bundle (.aab) with a current Flutter/Android toolchain.
- [ ] Ensure targetSdkVersion/API level 36 or higher for new Play submissions as required from 31 Aug 2026.
- [ ] Complete Play Console Data safety and app-content declarations accurately.
- [ ] Add screenshots, feature graphic and final app icon.
- [ ] Test Urdu RTL, search, favorites, cold start and Android back navigation on real devices.
